# 🎮 GameStore

Projeto desenvolvido utilizando apenas **HTML e CSS**, com o objetivo de criar um site simples para uma loja virtual de jogos eletrônicos.

## 📋 Sobre o Projeto

A GameStore é uma loja fictícia de games que apresenta:

- Página inicial com apresentação da loja;
- Tabela de preços dos principais jogos;
- Catálogo de produtos;
- Página institucional "Quem Somos";
- Formulário de contato.

O projeto foi criado para fins acadêmicos e prática de desenvolvimento web front-end.

---

- HTML5
- CSS3

## 🖥️ Funcionalidades

### Página Inicial
- Apresentação da GameStore;
- Imagem principal da loja;
- Tabela de preços dos jogos disponíveis.

### Produtos
- Exibição dos jogos disponíveis;
- Cards com imagem, nome e preço;
- Botão de compra ilustrativo.

### Quem Somos
- História da empresa;
- Missão da GameStore;
- Imagem institucional.

### Contato
- Formulário para envio de mensagens;
- Campo para nome, e-mail, motivo e mensagem;
- Informações alternativas de contato.
